# DataLens Community Hub

This repository is for issue tracking, feature requests, and community discussions for DataLens.

> Source code is maintained in a separate private/internal repository and is not hosted here.

## What to use this repository for

- Bug reports
- Feature requests
- Usage questions
- Release announcements and known issues

## Before opening an issue

Please include:

1. OS and Chrome version
2. DataLens version
3. Steps to reproduce
4. Expected behavior vs actual behavior
5. Screenshots or logs (if available)

## Security

If your report contains sensitive information, contact maintainers privately instead of posting a public issue.
